Open source · MIT · Runs on your machine

Stops the tool calls your agent didn't get from you.

Coding agents read READMEs, issues, web pages and MCP results. Any of them can carry an instruction. WithHuman traces every call back to its cause and holds back the ones you never asked for.

04 · Quickstart

Run it in five minutes

$ git clone https://github.com/BobWithHuman/withhuman-core.git
$ cd withhuman-core && cp .env.example .env
# set the values on the right
$ docker compose up --detach --wait
$ python3 deploy/client/configure.py --scope user \
    --team personal --server http://127.0.0.1:3000
POSTGRES_PASSWORDlong random
JEV_API_KEYjudging model key
WITHHUMAN_MODEenforce to block
GATEWAY_BIND127.0.0.1
